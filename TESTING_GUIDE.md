## Подготовка к тестированию

### 1. Запуск локальной среды

#### Вариант A: С помощью Docker Compose (рекомендуется)

```bash
cd /Users/dina.kich/GolandProjects/StorageAccounting/deployments
docker-compose up -d
```

Проверьте, что контейнеры запущены:
```bash
docker-compose ps
```

Должны быть запущены:
- `backend` (порт 8080)
- `postgres` (порт 5432)

#### Вариант B: Ручной запуск

1. **Запустите PostgreSQL**:
```bash
# Создайте базу данных
createdb inventory_db

# Примените миграции
psql -d inventory_db -f backend/migrations/001_create_items.sql
psql -d inventory_db -f backend/migrations/002_create_transactions.sql
```

2. **Настройте переменные окружения**:
```bash
export DATABASE_URL="postgresql://localhost:5432/inventory_db?sslmode=disable"
export TELEGRAM_BOT_TOKEN="your_bot_token_here"
export S3_ENDPOINT="your_s3_endpoint"
export S3_ACCESS_KEY="your_access_key"
export S3_SECRET_KEY="your_secret_key"
export S3_BUCKET="inventory-photos"
export SERVER_PORT="8080"
```

3. **Запустите backend**:
```bash
cd backend
go run cmd/server/main.go
```

4. **Запустите frontend** (для локального тестирования):
```bash
cd frontend
python3 -m http.server 8081
```

### 2. Проверка доступности сервисов

#### Проверка backend:
```bash
curl http://localhost:8080/health
```

Ожидаемый ответ:
```json
{
  "status": "healthy"
}
```

#### Проверка базы данных:
```bash
psql -d inventory_db -c "SELECT COUNT(*) FROM items;"
psql -d inventory_db -c "SELECT COUNT(*) FROM transactions;"
```

### 3. Тестовые данные

Создайте файл `test_data.sql` для вставки тестовых данных:

```sql
-- Вставка тестовых товаров
INSERT INTO items (name, current_quantity, created_by) VALUES
('Ноутбук Dell XPS 15', 10, 12345),
('Монитор Samsung 27"', 25, 12345),
('Клавиатура Logitech', 50, 12345),
('Мышь беспроводная', 100, 12345),
('Кабель HDMI 2м', 0, 12345);

-- Вставка тестовых транзакций
INSERT INTO transactions (item_id, user_id, previous_quantity, new_quantity, delta, note)
SELECT id, 12345, 0, current_quantity, current_quantity, 'Начальный остаток'
FROM items;
```

Примените тестовые данные:
```bash
psql -d inventory_db -f test_data.sql
```

```bash

time curl -H "X-Telegram-Init-Data: valid_init_data" \
  http://localhost:8080/api/items?limit=50

# Повторите 10 раз и вычислите среднее
for i in {1..10}; do

    http://localhost:8080/api/items?limit=50 > /dev/null
```

## Тестирование безопасности

### Тест безопасности 1: SQL Injection

**Шаги**:
```bash
# Попробуйте SQL инъекцию в параметрах
curl "http://localhost:8080/api/items?limit=50'; DROP TABLE items; --"

# Попробуйте в JSON body
curl -X POST \
  -H "Content-Type: application/json" \
  -d '{"name":"Test'; DROP TABLE items; --","quantity":10}' \
  http://localhost:8080/api/items
```

**Ожидаемый результат**:
- ✅ Инъекция не выполняется
- ✅ Параметры безопасно экранируются
