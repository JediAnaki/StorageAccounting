## 🛠️ Полезные скрипты

### `./test_system.sh` ⭐ РЕКОМЕНДУЕТСЯ

Автоматически запускает все тесты и выдает отчет.

```bash
# Запустить все тесты
./test_system.sh

# Или укажите URL вашего сервера
./test_system.sh http://your-server:8080
```

**Что проверяет:**
- ✅ Доступность сервисов
- ✅ CRUD операции
- ✅ Управление количеством
- ✅ Фильтрация транзакций
- ✅ Безопасность (401, 404, 409)
- ✅ Производительность (<200ms)

### `./reset_system.sh`

Сброс системы в начальное состояние.

```bash
./reset_system.sh
```

**Что делает:**
- Останавливает все сервисы
- Пересоздает базу данных
- Применяет миграции
- Опционально: добавляет тестовые данные

## 🚀 Рекомендуемый порядок действий

### Шаг 1: Запустите систему (5 минут)

```bash
# Вариант A: Docker (проще)
cd deployments
docker-compose up -d

# Вариант B: Локально
createdb inventory_db
cd backend
psql -d inventory_db -f migrations/001_create_items.sql
psql -d inventory_db -f migrations/002_create_transactions.sql
go run cmd/server/main.go
```

**Проверка:**
```bash
curl http://localhost:8080/health
# Должен вернуть: {"status":"healthy"}
```

## ❓ Частые вопросы

### Как запустить без Docker?

См. [QUICKSTART_RU.md - Вариант 2: Локальная разработка](./QUICKSTART_RU.md#вариант-2-локальная-разработка)

### Где взять TELEGRAM_BOT_TOKEN?

1. Откройте @BotFather в Telegram
2. Создайте бота: `/newbot`
3. Скопируйте токен

### Как сбросить систему?

```bash
./reset_system.sh
```

### Тесты не проходят, что делать?

1. Проверьте логи: `docker-compose logs backend`
2. Убедитесь, что БД доступна: `psql -d inventory_db -c "SELECT 1"`
3. См. раздел "Решение проблем" в [TESTING_GUIDE.md](./TESTING_GUIDE.md#решение-проблем)
